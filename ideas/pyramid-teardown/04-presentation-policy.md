## Roblox copycat policy
1. Creator Docs > Discovery > Issues that limit exposure: "Non-unique games – Games with metadata and place files that closely resemble existing games on Roblox are no longer prioritized for recommendations and might rank lower in search results. Example: A game with the same title and visuals as a previously published game."
2. First added 2024-12-09; current wording 2026-06-15. Ads Manager (2025-09-10): ads for such games "might not be effective… can result in no ad spend and no conversions".
3. Best practice: "Use unique metadata… original imagery and naming… Add your own spin to existing trends in the title, images, description, and in-game content." Dashboard banner shows when flagged; re-assessed on each update.
4. Creator Roadmap 2026: "deceptive game copy takedowns" (auto-takedown of games impersonating another's detail page) and "name checks", both late 2026.
5. Takeaway: copying the genre and systems is fine; copying the name, art, thumbnails, map or place file is not.
