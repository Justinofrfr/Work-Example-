# Build the Pyramid! — UI/HUD and monetization (research 2026-10-01; search snippets only, direct fetch blocked)

## Facts
- Universe/place 123720558354386, created Sep 3 2026 (Rolimons). Visits ≥13.15M (later record 15.8M). CCU 25,934 on Sep 28. Favorites 70K→81K. 95% likes.
- Server 50 players (cut from 100 on Sep 26 for lag). Pyramid = 171,700 blocks (one fan source says ~240,000).
- Badges: 0. Update 1.5 (Sep 22): more pyramids, more gym areas, bug fixes.

## HUD
- Top-left: codes (coupon) icon + settings cog. Physical CODES sign near the block pit.
- Codes panel: "Enter Code" box + green Redeem (one source says codes sit at the bottom of SHOP).
- Shop on the HUD's right side: stacking multipliers, Pharaoh pass, single-use block packs.
- Speed and Strength stats + coin counter on HUD.
- Pyramid counter icon (+1 per completion). Completion = cutscene + interior with 3 chambers.
- Server-wide block counter; per-project completion % for Basic, Silver, Gold, Void and Gem Pyramid (likely from Update 1.5).
- World UI: green path quarry → site; green highlight where you place; wooden FREE GIFT board at spawn; Coin-only upgrade stand.
- Rank titles by pyramids completed: Apprentice (0), Artisan (1), Chief Mason (8), Prophet of Ra, High Priest.
- Mobile: one "Block Pick Up / Interact" button, hold to repeat. PC: E.

## Coin upgrades (soft currency)
- Bulk Pickup: 50 / 300 / 850 / 2,400 / 6,600 Coins (1 → 5 blocks per grab)
- Bulk Place: 50 / 300 / 850 / 2,400 (1 → 4 per place)
- Placement Range: 25 / 150 / 425 (+0 / +10 / +20%)
